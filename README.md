# AWS Cloud Incident Response & Threat Detection Lab

## Executive Summary
This project simulates a real-world cloud security incident involving an AWS account compromise. An attacker obtained compromised credentials for an IAM user (`victim-employee`), established persistence via programmatic access keys, attempted privilege escalation, and exfiltrated sensitive data from an S3 storage bucket. 

As the Lead Cloud Incident Response Analyst, I conducted log investigation across AWS CloudTrail and GuardDuty, mapped the full attack lifecycle, correlated forensic indicators, and executed containment and remediation controls.
